# 혼잔 · 혼자 와도 혼자가 아닌 바

비 오는 밤 골목 끝 작은 바. 말없이 옆자리에 앉아 한 잔 하고 가요.

## 할 수 있는 것

- **앉기**: 빈 자리를 톡 눌러요. 바 8석, 창가 3석, 2인 테이블, 소파, 책 코너가 있어요.
- **🥂 짠 / 🥃 한 모금**: 옆자리 사람들이 잔을 들어 받아줘요.
- **📜 메뉴**: 소주, 하이볼, 생맥주, 레드 와인, 따뜻한 보리차, 무알콜 하이볼. 턱 괴기, 엎드리기 자세도 있어요.
- **✨ 더보기**
  - 📖 책 읽기: 책장 넘기는 소리가 나요.
  - 🌧 창문에 그리기: 창가 자리에서 김 서린 창에 그려요. 천천히 다시 흐려져요.
  - 🧻 냅킨 한 줄
  - 🐈 바 고양이 노가리
  - 🧾 오늘은 여기까지: 영수증을 받아요.
- **💿 LP**: 각자 고른 곡을 들어요. 빗소리, LP 지지직 소리와 함께 나와요.
- **🍶 바텐더한테 한 잔 사주기**: 자율 후원
- **마감**: 매일 02:00(한국 시간)에 문을 닫아요.

## 실시간 접속 켜기

`index.html` 위쪽의 `SUPABASE_URL`, `SUPABASE_KEY`를 채우면 실제 손님끼리 연결돼요. 비워두면 시뮬레이션 손님이 있는 데모로 열려요.

- Supabase Realtime의 Broadcast와 Presence만 써서 테이블은 필요 없어요.
- 한 가게에 20자리라, 꽉 차면 2호점·3호점으로 자동 안내해요.
- `?room=2`처럼 가게를 직접 고를 수도 있어요.

## 배포

빌드 없는 정적 페이지예요. Vercel에서 이 저장소를 Import하면 바로 배포돼요.
